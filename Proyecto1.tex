\section*{Introduccion}

Se debe crear un chat en línea al que multiples clientes puedan acceder y comunicarse entre ellos,se necesitan crear tanto un servidor como un cliente.
El servidor se encargará de recibir las conexiones de los clientes, procesar los mensajes que reciba de ellos y actuar conforme a este, además de enviar respuestas a los mensajes y comunicar a otros clientes de algún cambio hecho.

El cliente es un usuario del servidor, debe poder conectarse a él y realizar operaciones, además de esperar respuestas del servidor y otras notificaciones de cambios en el chat.

Las operaciones que el usuario debe poder hacer en el chat son:

\begin{itemize}
\item \textbf{Identificarse:} ingresa un nombre de usuario válido
\item \textbf{Introducción:} Descripción del proyecto, objetivo y la importancia de conocer esta información.
\item \textbf{Asignarse un estado:} Escoger entre: ACTIVE, BUSY, AWAY.
\item \textbf{Ver usuarios:} Puede pedir la lista de usuarios conectados en el servidor.
\item \textbf{Enviar un texto privado:} Tener mensajes directos con otro usuario.
\item \textbf{Enviar un texto publico:} Mandar mensajes a todos los usuarios.
\item \textbf{Crear una sala:} Crear un espacio donde solo los usuarios invitados puedan unirse.
\item \textbf{Ver usuarios en una sala:} Pedir la lista de usuarios en una sala.
\item \textbf{Enviar mensaje a una sala:} Mandar mensajes a todos los usuarios en una sala.
\item \textbf{Enviar mensaje a una sala:} Mandar mensajes a todos los usuarios en una sala.
\item \textbf{Salir de una sala:} Salir de una sala a la que pertenezca.
\item \textbf{Desconectarse:} Salir del servidor y de todas las salas a la que pertenezca.    
\end{itemize}


Para que multiples clientes, incluso de diferentes computadoras se comuniquen con el servidor y viceversa se debe usar el protocolo establecido, entonces, usando JSON (JavaScript Object Notation, o notación de objetos en JavaScript), el servidor debe ser capaz de recibir los mensajes del cliente y actuar conforme a ellos y el cliente debe poder enviar los JSON al servidor, conforme a lo que el usuario pida (el usuario no debe escribir los JSON).

\section*{Analisis y diseño}

Como se explicó en la introducción, el chat se divide en dos partes, \textbf{Cliente} y \textbf{Servidor}, que deben poder funcionar con cualquier otro cliente y cualquier otro servidor, por lo que creé dos programas distintos, llamados, evidentemente, cliente y servidor:

\subsection*{Cliente}
\subsubsection*{Analisis}
El cliente decidí hacerlo en ``c\#'', porque pensé inicialmente en hacer una interfaz gráfica (que no hice), pero me quedé con él porque es un lenguaje orientado a objetos, lo que me permitió hacer mis distintas clases para formar al cliente, e incluso poder separar la vista del modelo.
El cliente es el que representa al usuario y debe tener las operaciones descritas antes, entonces lo que hace el cliente, es básicamente:
\begin{itemize}
\item \subsubsection*{Conectar al cliente al servidor}
  Debe poder recibir y usar los datos del puerto y  la dirección que el usuario especifique para conectarse al servidor.
\item \subsubsection*{Mandar mensajes al servidor}
  Recibir las cadenas que el usuario escriba (el usuario no debe escribir el JSON), y ``traducirlas'' formando el JSON que se enviará al servidor.
\item \subsubsection*{Recibir mensajes del servidor}
  Recibir los JSON que mande el servidor y comunicarlos al cliente de manera comprensible.
\item \subsubsection*{Comunicar los mensajes al usuario}
  Recibir los JSON que mande el servidor y comunicarlos al cliente de manera comprensible.  
\end{itemize}

  \subsection*{Servidor}

  El servidor es el que debe recibir a los clientes, procesar sus mensajes y actuar conforme a ellos:
  \begin{itemize}
  \item \subsubsection*{Conectarse a la red}
    Debe poder recibir y usar los datos del puerto y  la dirección que el usuario especifique para conectarse al servidor.
    Para esto tengo la clase Servidor, con el método sirve(), el puerto se lee en el Main y se pasa como parámetro al hacer el Servidor
  \item \subsubsection*{Recibir clientes}
    Siempre recibir nuevos clientes.
    Esto igual es en el método sirve que usa el hilo principal para siempre recibir los clientes.
  \item \subsubsection*{Realizar las operaciones pedidas}
    Dependiendo del mensaje del cliente debe realizar las operaciones.
    En la clase servidor, el método sirve, usa el método leeCliente que es el que realiza una operación dependiendo el JSON recibido.
  \item \subsubsection*{Mandar los mensajes}
    Después de realizar las operaciones debe mandar respuestas al cliente o mensajes a los demás clientes.
    En cada método construyo los JSON para enviar al cliente dependiendo la operación, tengo enumeraciones que hice pensando en hacer más fácil obtener las respuestas y mensajes, pero al final solo la usé en un método.
  \item \subsubsection*{Otras clases}
  \item Conexión: es un mapa para guardar los usernames y su numero de socket.
  \item Conexión: es un mapa para guardar los usernames y su numero de socket.
  \item Sala: Tiene una lista de usuarios y un set de invitados, la sala general es a la que entran todos y luego Servidor tiene un mapa de salas que guarda su nombre y su creador.
  \item ListaUsuarios: es un mapa para guardar a los usuarios junto con su estado, muy util para cuando piden la lista de usuarios en una sala o en el chat general.
  \item Bitacora: Imprime los mensajes para el servidor.
  \item Mensaje: enumeraciones para crear o deseriar los JSON, pero me terminó confundiendo más así que solo las usé en un método.
    
    
  \end{itemize}

  \section*{Resumen}
  Durante este proyecto se creó un chat en línea en el que múltiples clientes se puedan conectar y mandar mensajes entre ellos, utilizando otras diversas operaciones dentro de el chat, se tiene  una sala general para todos los usuarios y que además cada uno pueda hacer sus salas privadas, invitando a otros usuarios, también podrán solicitar la lista de usuarios conectados, tanto para la sala general como para las que son parte, actualizar su estado, y desconectarse del chat.
